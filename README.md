# Version 1 HT Lab

ThermoLab: A High-Fidelity Digital Heat Transfer Laboratory for Chemical Engineering.

## 🚀 Live Deployment
This project is configured for deployment on **Streamlit Cloud**.

### How to Deploy:
1. Create a new repository on GitHub named `Version 1 HT Lab`.
2. Push this local repository to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/Version-1-HT-Lab.git
   git branch -M main
   git push -u origin main
   ```
3. Connect to [Streamlit Cloud](https://share.streamlit.io/) and select this repository.

## 🧪 Included Experiments

2. Shell-and-Tube Heat Exchanger

4. Forced Convection (Wind Tunnel)

6. Air-Cooled Heat Exchanger
7. Natural Convection
8. Pin-Fin Apparatus
9. Composite Wall Conduction
10. Radiation & Emissivity

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS 4.
- **Physics**: RK4 Numerical Integrator.
- **Deployment**: Streamlit Python Bridge.
